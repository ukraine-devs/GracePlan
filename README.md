# Grace Planner

API-backed Grace Plan chat for visitors without requiring a ChatGPT account.

## Local

```bash
npm install
npm run dev
```

## Vercel

The project builds with:

```bash
npm run build
```

Required environment variable:

```bash
OPENAI_API_KEY=...
```

Optional model override:

```bash
OPENAI_MODEL=gpt-4.1-mini
```
