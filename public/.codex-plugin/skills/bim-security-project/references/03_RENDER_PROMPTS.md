# Концептуальные рендеры

Формируй промпт заново для конкретного проекта по предоставленным планам, фотографиям, ограничениям и подтвержденным материалам. Не включай исторические адреса, координаты, названия помещений, оборудование или исходные данные других объектов.

Для каждого рендера укажи цель, источник плана/фото, согласованные пространственные ограничения, что можно интерпретировать, а что нельзя менять. Маркируй результат как концептуальный, если он не получен из проверенной параметрической модели. Не утверждай геометрическую точность по одному изображению.

Для точных электрических и сетевых схем применяй программное векторное построение. Сохраняй исходные файлы, параметры генерации и замечания приемки.
