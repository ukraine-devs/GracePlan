# Стартовый запрос для нового проекта

Работай только с материалами, предоставленными для текущего объекта. Сначала определи цель, ограничения и формат результата; перечисли файлы и проверь их целостность. Сохрани оригиналы, создай реестр планов/фото и зафиксируй ревизии.

Затем выполни подтвержденные части цикла: связь фото с помещениями, калибровку геометрии, визуальные/концептуальные материалы, инженерные планы, детерминированные расчеты и смету с текущими источниками. Не переноси данные других проектов. Явно обозначай допущения и неподтвержденные выводы.

Для каждой команды зафиксируй входы, ревизию, выходные файлы, проверки, статус и нерешенные вопросы. После каждого изменения исходников обнови зависимые результаты. Заверши файлами, отчетом проверки и кратким описанием ограничений.
